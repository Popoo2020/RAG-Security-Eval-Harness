# RAG Security Evaluation Harness - Case Study

## Problem

RAG systems can fail when retrieved content is treated as trusted instructions instead of untrusted context.

## Solution

This project demonstrates a deterministic evaluation baseline for RAG-style risks:

- source-trust labelling,
- retrieval-risk indicators,
- instruction-override signal checks,
- dataset-driven test cases,
- and generated summary reporting.

## Outcome

The project shows how RAG security concerns can be evaluated through repeatable tests and visible report artefacts instead of vague guardrail claims.

## Portfolio value

Relevant for AI Security, secure RAG, LLM application security, Cyber GRC and AI risk evaluation roles.
