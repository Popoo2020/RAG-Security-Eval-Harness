# Hiring Manager Summary

## What this project demonstrates

RAG-Security-Eval-Harness demonstrates a structured way to evaluate retrieval-augmented generation workflows for source-trust and hostile-content risks.

It focuses on dataset-driven checks, retrieval-poisoning indicators, indirect instruction risks and explainable risk levels.

## Relevant roles

- AI Security Analyst
- Secure RAG / LLM application reviewer
- AI Governance Consultant
- Cybersecurity GRC Consultant
- Security Engineer working with enterprise AI systems

## What this demonstrates

- Awareness of retrieval poisoning and indirect prompt-injection risks.
- Separation of trusted, untrusted and mixed-source content.
- Dataset-driven evaluation rather than vague guardrail claims.
- Repeatable report generation.
- CI validation, linting and dependency audit.

## Current limitations

This is a deterministic baseline. It does not yet include live vector-store integration, model-in-the-loop benchmarking or statistical false-positive / false-negative scoring across a large corpus.
