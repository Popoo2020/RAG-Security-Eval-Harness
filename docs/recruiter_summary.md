# Recruiter Summary

**RAG-Security-Eval-Harness** is a portfolio-grade AI security testing project focused on retrieval-augmented generation risks.

## One-sentence summary

A deterministic evaluation harness for testing RAG-style systems against source-trust problems, retrieval poisoning and indirect prompt-injection patterns.

## What it proves

- Understanding of RAG-specific security risks.
- Ability to build dataset-driven security evaluations.
- Practical AI security testing mindset.
- Clear separation between trusted and untrusted retrieved context.
- Ability to generate reviewable reports from test cases.

## Best-fit roles

- AI Security Engineer
- LLM Application Security Analyst
- Cybersecurity GRC / AI risk roles
- Responsible AI / AI Governance Analyst
- Security automation and evaluation roles

## Interview talking points

1. Why retrieved context can become an attack surface.
2. How indirect prompt injection differs from direct prompt injection.
3. Why source trust and provenance matter in RAG systems.
4. How deterministic test cases can support repeatable AI security review.
5. What metrics could be added next: false positives, false negatives and model-specific behaviour.

## Current maturity

This is a strong evaluation baseline. Future work could add larger datasets, OWASP LLM Top 10 mapping, scoring metrics and optional live-model evaluation mode.
